# Retail Business Performance & Profitability Analysis

## Project Overview
This project analyzes retail sales data to identify business performance, profitability, and sales trends using Python and Power BI.

## Objectives
- Analyze total sales, profit, and quantity sold.
- Compare sales and profit across product categories.
- Identify profitable and loss-making sub-categories.
- Compare sales performance across regions.
- Present business insights through visualizations and a dashboard.

## Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Microsoft Power BI

## Dataset
Sample Superstore dataset containing 9,994 retail transactions.

## Key Findings
- Total sales: approximately $2.30 million.
- Total profit: approximately $286,397.
- Technology generated the highest category sales and profit.
- Furniture generated comparatively lower profit.
- Tables recorded the largest sub-category loss, approximately $17,725.
- The West region recorded the highest sales.

## Project Files
- `Sample_Superstore.csv` – Dataset
- `retail_analysis.py` – Python analysis and visualization code
- `Retail_Business_Analysis.pbix` – Power BI dashboard
- `Retail_Business_Analysis.pdf` – PDF dashboard report
- PNG files – Generated visualizations

## Conclusion
The analysis highlights differences in sales and profitability across categories, sub-categories, and regions. It helps identify areas of strong performance and potential business improvement.
